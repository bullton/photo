评分方法与限制

照片会缩到长边 1600px，在亮度通道计算拉普拉斯方差。NEF 以及转换后的 DNG 都会读取相机保留的对焦信息（尼康 AFInfo2）：自动/宽区域 AF 直接按对焦框评分，单点 AF 则以对焦点为中心取更大主体区，用区内分块方差的中位数评分；中位数能避免一条锐利边缘掩盖整体发虚。Z30 这类只记录 81 点自动区域对焦点、不写对焦框的机型，会把用到的对焦点合并成一个主体区再评分。没有对焦信息时，退回画面中心区评分。

分数主要是这一批照片内的相对值，用来突出谁更合焦；个别极锐的样本不会把整批阈值抬得过高。若整批分数连绵、找不到明显断点，会自动按「主体清晰度下限」兜底分档，避免阈值退化为 0 而把整批都判成合焦；可随时拖动滑块微调。自动区域 / 宽区域 AF 时对焦框可能偏大，精度会下降，建议结合大图核对。

先按 EXIF 拍摄时间把时间上连续的照片划为疑似连拍组（严格 2 秒 / 标准 3 秒 / 宽松 45 秒 / 更宽松 3 分钟），再只在组内按「文件名连拍序号 + 感知哈希 + 画面亮度 + 颜色布局」自动归组，组内按清晰度从高到低排列，默认不打星（工具栏可开启每组自动 1–3 星）。分析后先按相似组排列：多张的组用组内平均分、单张用自己的分数，一起从高到低排序；组内再按清晰度从高到低排列。这样一张一张翻看时就是优先看高分照片。星级可以随时手动改成 0–5 星。

曝光只做粗分：高光溢出达到 8% 判为过曝，平均亮度很低且暗部堆积判为欠曝；它只作为组内排序的轻微扣分项，不会取代清晰度判断。

纹理很少的画面（大面积天空、纯色背景）会标为「低纹理」并归入临界，避免被误删。相对分数只适合同一批比较。HEIC 需先转 JPEG。照片只在本地浏览器中处理，刷新后需重新拖入。RAW 会额外缓存相机内嵌的全分辨率 JPEG，刷新后 1:1 仍可查看原始像素（约 3 MB/张，清空批次后释放）。星级可以写成同名 XMP 侧车文件供 Lightroom Classic 读取（Rating 0–5）；已有 XMP 只改 Rating，不会覆盖修图参数。
